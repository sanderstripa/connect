Connect 0.1.0 · Windows 10/11 x64 · первый предварительный выпуск

- Интерфейс на основе sudoku-app: Montserrat, монохромная палитра, светлая/тёмная/системная темы и одна кнопка подключения.
- Переключение Sudoku, Xray и Mist. Xray поддерживает VLESS/VMess/Trojan и сохраняет параметры xhttp.
- Встроенные ядра Sudoku 0.5.1, Xray 26.3.27, Mist и TUN-контур HEV.
- Установщик с русским/английским интерфейсом и дополнительным компонентом Chrome.
- Независимый браузерный помощник с отдельными профилями. В панели — питание и настройки; протоколы выбираются в настройках.
- Chrome: после установки нужно один раз загрузить ChromeExtension через chrome://extensions. ZIP расширения требует установленного native helper.
- Проверены настоящий локальный HTTP через Xray/xhttp и Sudoku, переключение активного протокола, TCP/UDP адаптера Mist, Windows-совместимые Go-тесты и интерфейс.

Ограничения: удалённые серверы пользователя, TUN в реальной сети и подключение Mist к внешнему Edge не проверены. Mist экспериментальный; исключения для него не поддерживаются. Один активный профиль Chrome на пользователя Windows. Приложение и установщик не подписаны.

Connect 0.1.4 · Windows 10/11 x64 · предварительный выпуск

- Иконка трея полностью переделана: используется исходная иконка приложения, без замены геометрии рисунка. Серебристые линии становятся зелёными при активном VPN; чёрный фон сохраняется.
- Добавлены размеры иконки для масштаба Windows. Размер выбирается перед передачей в трей, без прежнего двойного уменьшения.
- В заголовке настроек приложения рядом с кнопкой сворачивания добавлен переключатель RU/EN. Интерфейс меняет язык сразу; выбор сохраняется и не сбрасывает несохранённые настройки.

Сохранённые профили остаются на месте. После обновления перезагрузите Connect один раз на chrome://extensions. Ключи не включены. Mist экспериментальный. EXE не подписаны.

Connect 0.1.5 · Windows 10/11 x64

### New identity

The application icon has been redrawn as a vector from the supplied signal-and-peak reference. The same source now produces every brand asset:

- Windows application, installer, uninstaller and shortcut icons, including 12 embedded ICO sizes from 16 to 256 px.
- Chrome toolbar, extension management and installer images, with dedicated size variants.
- Tray icons for Windows display scaling, including the green connected state.
- Repository branding, legacy interface assets, Linux app image and macOS ICNS/template assets.

Small variants are rendered directly from vector geometry with additional optical sizing. The space outside the circular mark is transparent.

### Updating

Quit Connect from its tray menu before installing. Saved profiles remain intact. Reload the Chrome extension once at `chrome://extensions` after updating. Windows may keep an older shortcut image in its icon cache until Explorer refreshes.

This release changes branding only. It does not claim to fix the intermittent connectivity issue reported during testing. Mist remains experimental. Executables are unsigned. No server credentials are included.

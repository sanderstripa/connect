Connect 0.1.1 · Windows 10/11 x64 · предварительный выпуск

- Установщик автоматически открывает chrome://extensions и копирует путь к расширению. Осталось включить режим разработчика и подтвердить загрузку папки; шаг можно повторить кнопкой установщика.
- Перерисована иконка трея для малого размера, отдельно для светлой и тёмной темы. При активном ядре и TUN она становится зелёной.
- Sudoku ↔ Xray с IPv4-адресами и общим локальным портом переключаются без пересоздания TUN и DNS. Проверяется настоящий HTTP-трафик, при отказе нового ядра восстанавливается предыдущий профиль. Повторный выбор активного протокола не перезапускает VPN.
- Ускорен поиск адаптеров и физических маршрутов Windows через системный API. Убрана блокировка UDP/443, мешавшая транспорту; HEV MapDNS одинаков для всех протоколов.
- Проверены четыре переключения подряд с настоящими Xray/xhttp и Sudoku, передача HTTP и восстановление после отказа ядра. Тест сохраняет процесс сетевого контура и не меняет системные маршруты. Также проверены приложение, расширение, установщик и интерфейс.

Доменные/IPv6 адреса, разные локальные порты и Mist используют полный перезапуск. Удалённые профили Sudoku и Xray проверены через изолированный помощник без изменения системных маршрутов. Реальная работа TUN в сети пользователя не проверена. Mist остаётся экспериментальным; его транспорт в этом обновлении не менялся. EXE не подписаны. Ключи пользователя не включены.

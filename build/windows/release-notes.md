Connect 0.1.3 · Windows 10/11 x64 · предварительный выпуск

- В заголовке расширения добавлены переключатели русского/английского языка и светлой/тёмной темы. Выбор сохраняется между открытиями панели.
- Стрелка возврата выровнена с заголовком. Убрана чёрная обводка полей ввода.
- Обычное отключение больше не вызывает сообщение об обрыве из-за запоздавшего уведомления помощника. Сообщения расширения отображаются спокойным цветом.
- В приложении скрыто старое уведомление службы при выключенном VPN. Ошибки текущих действий и восстановления маршрутов остаются видимыми.
- В трее теперь знак приложения: чёрный круг с серыми линиями, которые становятся зелёными после включения VPN.

Все профили сохраняются. После обновления перезагрузите Connect один раз на странице chrome://extensions. Ключи пользователя не включены. Mist остаётся экспериментальным; транспорт не менялся. EXE не подписаны.

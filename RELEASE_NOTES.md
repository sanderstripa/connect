# Connect VPN 1.5.1

- Установка и повторная подготовка расширения Chrome из настроек Connect VPN.
- Локальное согласование системного и браузерного VPN с подтверждением переключения.
- Установщик Windows x64 и отдельный архив расширения Chrome. При обновлении сохраняются профили и настройки.

Расширение загружается на странице `chrome://extensions`. Включите режим разработчика и выберите «Загрузить распакованное расширение». Для уже установленного расширения из той же папки нажмите «Обновить».
